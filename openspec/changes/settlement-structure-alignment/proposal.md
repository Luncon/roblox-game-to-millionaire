# Proposal

## Why

Sparta level 12 visibly floats above its foundation, and shared construction code repeats the issue across civilization themes. Fixed roof elevations and unchecked neighboring structures also produce detached roof sections, unsupported beams and late-level building intersections.

## What Changes

- Ground settlement architecture, purchased buildings and rural architectural pieces on their actual supporting surface; provide real supports for pillars, roofs, fence rails and physical signs and every upgrade pad.
- Derive pitched-roof height from wall width and slope, preserving civilization themes and filling the supported attic beneath each roof.
- Adjust the grand longhouse footprint and ceremonial gate arrangement to clear each other and the level-30 perimeter.
- Add native geometry regressions across thirteen civilizations, fifty levels and transformed worlds, alongside before/after views of Sparta level 12.
- Preserve pad locations and purchase behavior, troop access, growth identity, progression, economy, saving, combat and source assets. No architectural asset replacement, new buildings or gameplay systems are included.

## Capabilities

### New Capabilities

- `settlement-geometry`: Supported settlement construction, roof/wall joins and clearance between separate structures throughout growth and infrastructure restoration.

### Modified Capabilities

None; the main specification inventory currently contains only development workflow.

## Impact

SettlementBuilder, SettlementDistricts and SettlementInfrastructure construction; a shared server geometry helper; focused and exhaustive Studio tests; world/playtest documentation. No profile schema, dependencies, authority boundaries or existing `.rbxl` asset changes are required. The user requested the fix on `fix/settlement-structure-alignment`.
