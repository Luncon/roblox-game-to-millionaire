## Writing a note

Use a descriptive filename, optionally prefixed with `YYYY-MM-DD`. Record the
context, observations or decision, evidence where available, and open questions
or follow-up work. Distinguish an idea from an agreed decision and a planned
feature from verified behavior. Store images in `docs/assets/` and use relative
Markdown links.
