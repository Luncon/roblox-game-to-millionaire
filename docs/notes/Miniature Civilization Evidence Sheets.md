# Miniature civilization evidence sheets

Latest revision: [Simple Shop and Automatic Troops](Simple%20Shop%20and%20Automatic%20Troops.md)
records the current research-free shop, automatic building-owned groups under ten
and expanded map. Older research/inspection/roster milestones below are history.


October 29, 2026. Native Studio renders of all thirteen original kit candidates:
**117 building models and 39 passive role figures**, at quarter scale.

Each overview reads left-to-right by rows: **civic/trade, house, farm**;
**timber, clay, pottery**; **store, training, healer**. The close-ups show
**frontline, missile, support** from left to right. Roles are inert presentations;
these images establish no damage, healing, mounts or conquest. Gallery props
were rearranged only for photography; authoritative budgets and footprints stay
unchanged. Billboard labels were not present in the Edit captures, so this key
and the linked source cards identify every role.

The native factory checks passed footprints/cardinal rotations, scale, inertness,
source immutability and role props. The [all-thirteen live UI tour](../assets/miniature-kit-tour-native-2026-10-29.json)
also passed real selector switches, previews, civilization labels, normal unarmed
commanders, W-key walking and farm inspection, retaining the plot and Spartan
progress. [Gallery metadata](../assets/miniature-kit-gallery-2026-10-29.json)
records counts and camera views. These are original game interpretations grounded
in the cited periods/regions, not certified archaeological reconstructions.
Uncertain domestic roofs, some work/storage/care forms and provisional farmer
clothing remain explicit in the source cards. Physical-device and published
multiplayer acceptance remain separate.
