## Decision

Use Obsidian for project notes and navigating the existing documentation. The
user requested this after reviewing the original October 13 vault setup.

workspace affect the same Markdown files.

## Workflow

- Start from [the vault home](../../START_HERE.md).
- Record ideas, decisions, references and playtest observations here, and link
  new notes from [the notes index](INDEX.md).
- Update existing topic documentation when an agreed decision changes it.
- Keep approved feature requirements and implementation tasks in OpenSpec;
  notes link to those artifacts.
